# Complete Web Development Course – JavaScript

Welcome to my **JavaScript learning repository**! 🚀  
This repo contains notes, code snippets, and practice projects from my journey through the Complete Web Development Course.

---

## 📚 Topics Covered

### 1. JavaScript Basics
- Variables (`let`, `const`, `var`)
- Data types (string, number, boolean, null, undefined, object)
- Operators (arithmetic, comparison, logical)
- Control flow (`if`, `else`, `switch`, loops)

### 2. Functions
- Function declarations & expressions
- Arrow functions
- Parameters & return values
- Scope & closures

### 3. DOM Manipulation
- Selecting elements (`getElementById`, `querySelector`)
- Changing content & styles
- Event listeners
- Creating & removing elements dynamically

### 4. Advanced JavaScript
- ES6+ features (template literals, destructuring, spread/rest)
- Promises & async/await
- Modules (`import` / `export`)
- Error handling (`try...catch`)

### 5. Object-Oriented Programming
- Objects & prototypes
- Classes & inheritance
- `this` keyword
- Encapsulation & abstraction

### 6. Browser APIs
- LocalStorage & SessionStorage
- Fetch API
- JSON handling
- Timers (`setTimeout`, `setInterval`)

### 7. Projects & Practice
- Mini calculator
- To-do list app
- News app with infinite scroll
- Responsive UI components
